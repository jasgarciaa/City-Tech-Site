## Spacing Scale

Multiples of 4 only. Established in Phase 1; unchanged in Phase 3.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, checkbox-label gaps, tight inline padding |
| sm | 8px | Compact field stack gaps, badge padding |
| md | 16px | Default field spacing (`space-y-4`), section padding |
| lg | 24px | Form group separation, section padding (`px-6`) |
| xl | 32px | Card/container padding (`p-8` on desktop form wrapper) |
| 2xl | 48px | Major section breaks, page vertical padding (`py-12`) |
| 3xl | 64px | Page-level top/bottom on wide viewports |

Exceptions:
- Touch targets: minimum 44px height on all interactive elements (Button, SelectTrigger, checkbox click zones) — LAYOUT-03
- Form max-width: `max-w-2xl` (672px) on the /request-service page container
- Intro area (Call Now + email block): `rounded-lg bg-primary/5 p-6` — lg spacing for visual separation before form

## Typography

Base font size: 17px (set on `html` in globals.css — established Phase 1, do not change).

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 16px (approx. 0.94rem at 17px base) | 400 regular | 1.5 | Form field input text, helper text, checkbox labels, paragraph copy |
| Label | 14px (`text-sm`) | 500 medium | 1.4 | Form field labels (`<Label>`, `<FormLabel>`), category group headings in checkbox grid |
| Heading | 20px (`text-xl`) | 600 semibold | 1.3 | Section headings within the page (`h2`), form section titles |
| Display | 28px (`text-2xl`) | 600 semibold | 1.2 | Page `h1` on /request-service: "Request Service" |

Note: shadcn `text-sm` = 0.875rem = ~14.9px at 17px base. This rounds to 15px effective. Treat all label-role text as "small/compact" — use `text-sm font-medium`.

## Color

All tokens defined in `app/globals.css` under `:root`. No new tokens introduced in Phase 3.

| Role | Token | Hex | Usage |
|------|-------|-----|-------|
| Dominant (60%) | `--background` | `#FFFFFF` | Page background, form card surface, input backgrounds |
| Secondary (30%) | `--secondary` / `--muted` | `#F3F4F6` | Intro area tint (`bg-primary/5` ≈ light blue wash), muted text zones, disabled state backgrounds |
| Accent (10%) | `--accent` | `#00AEEF` | Success icon (`CheckCircle2`), active checkbox accent (`accent-primary`), "Add more details" trigger text color (`text-primary`), Call Now button hover ring |
| Primary | `--primary` | `#1B3A8F` | Primary CTA button bg, "Call Now" button, form submit button, focus ring color (`--ring`) |
| Destructive | `--destructive` | `#DC2626` | Inline field validation error text, error border on invalid inputs (`border-destructive`), error alert banner |
| Foreground | `--foreground` | `#111827` | All body text, headings |
| Muted foreground | `--muted-foreground` | `#6B7280` | Category group labels ("Electronics", "Locksmith"), helper text, placeholder text |
| Border | `--border` / `--input` | `#E5E7EB` | Default input borders, card borders, accordion border |

Accent (`#00AEEF`) reserved for:
- Success state icon only (`CheckCircle2` on form confirmation)
- Checkbox `accent-color` CSS property on native checkboxes

Primary (`#1B3A8F`) is the active interactive color — used for:
- "Submit Request" button background
- "Call Now — (703) 343-6234" button background
- "Add more details (optional)" AccordionTrigger text
- Focus ring on all inputs and interactive elements

## Interaction States

### Form Field States

| State | Visual |
|-------|--------|
| Default | `border-input` (E5E7EB), white background |
| Focus | `ring-2 ring-ring` (1B3A8F), `border-ring` |
| Invalid | `border-destructive` (DC2626) + `<FormMessage>` below field in `text-sm text-destructive` |
| Disabled | Tailwind `disabled:opacity-50 disabled:cursor-not-allowed` (shadcn defaults) |

### Form Submission States

| State | Visual Contract |
|-------|----------------|
| `idle` | Form visible, submit button enabled |
| `loading` | Submit button shows `Loader2` spinner + "Sending...", `disabled`, form fields remain visible but non-interactive |
| `success` | Form replaced by success card: `CheckCircle2` icon (accent color) + heading "Request Received" + body "Thanks — we'll reach out shortly to confirm and quote your service." |
| `error` | Form stays visible; `role="alert"` error paragraph below submit button: "Something went wrong. Please call us directly at (703) 343-6234." in `text-sm text-destructive text-center` |

### Accordion Animation

Uses `tw-animate-css` classes already imported in globals.css:
- Open: `data-[state=open]:animate-accordion-down`
- Close: `data-[state=closed]:animate-accordion-up`
- No custom animation needed — Radix + tw-animate-css handles it

## Accessibility Requirements

- All form fields: `<label>` associated via `htmlFor` / `id` (enforced by shadcn `<FormLabel>` + `<FormControl>`)
- Invalid fields: `aria-invalid="true"` + `aria-describedby` pointing to error message id (shadcn `<FormMessage>` handles this)
- Error alert banner: `role="alert"` on submission error paragraph
- Success state: `role="status"` or `aria-live="polite"` region announcing result
- Checkbox group: wrapped in `<fieldset>` with `<legend>` "Services Needed" (screen reader association)
- Accordion trigger: keyboard operable via Enter/Space (Radix default)
- Minimum touch target: 44px height on all Button, SelectTrigger, and checkbox label click zones
- Heading hierarchy on /request-service: `h1` "Request Service" → `h2` (if sub-sections added) — no skipped levels
- Semantic landmark: page content in `<section>` with implicit region role; form in `<form>` element
