# Phase 1 — UI Design Contract: Foundation

> Visual and interaction contract for the design system tokens, sticky header, and global footer.
> Generated by gsd-ui-researcher. Verified by gsd-ui-checker.

## Design System

| Property | Value |
|----------|-------|
| Tool | shadcn/ui |
| Preset | manual init — `npx shadcn@latest init` (no preset URL; configure interactively) |
| Component library | Radix UI (via shadcn) |
| Icon library | Lucide React (bundled with shadcn) |
| Font | Inter (Next.js default, loaded via `next/font/google`) |

## Color System

### Token Definitions (Tailwind v4 `@theme {}` / shadcn CSS custom properties)

These are declared in `app/globals.css`. shadcn components reference the `--primary`, `--accent`, etc. tokens automatically via Radix UI's theming layer.

```css
@import "tailwindcss";

@theme {
  /* Brand blues — sampled from City Tech logo PNGs at project init */
  --color-brand-primary: #1B3A8F;   /* Dark royal blue — van body, wordmark */
  --color-brand-accent: #00AEEF;    /* Cyan/sky blue — key graphic, "Est. 2016" */

  /* Neutral surfaces */
  --color-white: #FFFFFF;
  --color-muted: #F3F4F6;           /* Warm grey — section backgrounds, dividers */
  --color-foreground: #111827;      /* Near-black — body text */
  --color-muted-foreground: #6B7280; /* Subdued text — captions, placeholders */

  /* shadcn semantic aliases */
  --primary: var(--color-brand-primary);
  --primary-foreground: #FFFFFF;
  --accent: var(--color-brand-accent);
  --accent-foreground: #FFFFFF;
  --background: var(--color-white);
  --foreground: var(--color-foreground);
  --muted: var(--color-muted);
  --muted-foreground: var(--color-muted-foreground);

  /* Destructive */
  --destructive: #DC2626;
  --destructive-foreground: #FFFFFF;

  /* Border and ring */
  --border: #E5E7EB;
  --ring: var(--color-brand-primary);

  /* Border radius */
  --radius: 0.375rem; /* 6px — professional, not trendy pill */
}
```

### Color Role Table (60/30/10 split)

| Role | Token | Hex | Usage |
|------|-------|-----|-------|
| Dominant (60%) | `--background` | `#FFFFFF` | Page background, card surfaces, header background |
| Secondary (30%) | `--muted` | `#F3F4F6` | Footer background, alternating section backgrounds, nav dropdown panel |
| Accent (10%) | `--accent` | `#00AEEF` | Accent reserved list (see below) |
| Primary | `--primary` | `#1B3A8F` | Call Now button fill, primary CTA buttons, active nav indicator |
| Destructive | `--destructive` | `#DC2626` | Destructive actions only (not applicable in Phase 1) |

**Accent (`#00AEEF`) reserved exclusively for:**
1. The "Est. 2016" badge text in the footer Brand column
2. The key/lock icon color in the Locksmith services nav dropdown group header
3. Inline hover underline accent on footer service links
4. Focus ring on the Call Now button when reached via keyboard (paired with `--ring`)

**Accent is NOT used for:** body text, section backgrounds, form inputs, general links.

**Light mode only.** No dark mode toggle. No `prefers-color-scheme` media query. No `dark:` Tailwind variants.

**Hex value note:** `#1B3A8F` and `#00AEEF` are approximate values extracted from the logo description. At project init, the executor must open the provided logo PNG files in a color picker and sample exact hex values. If sampled values differ by more than 5 delta from these approximations, update both the `@theme {}` block and this spec. The two-blue system is logo-derived, not a design choice.

## Typography

### Font Loading

```tsx
// app/layout.tsx
import { Inter } from 'next/font/google'

const inter = Inter({
  subsets: ['latin'],
  variable: '--font-inter',
  display: 'swap',
})
```

Add `className={inter.variable}` to the `<html>` element. Reference as `font-[var(--font-inter)]` in Tailwind or set `font-family: var(--font-inter)` as the base in `@theme {}`.

### Scale

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 16px | 400 (regular) | 1.6 | All paragraph text, dropdown descriptions, footer copy |
| Label | 14px | 400 (regular) | 1.4 | Nav link labels, button labels, footer column headers, badge text, nav group labels (uppercase + letter-spacing: 0.08em provides visual distinction) |
| Heading | 20px | 600 (semibold) | 1.3 | Section headings, nav dropdown group labels ("Electronics", "Locksmith") |
| Display | 28px | 600 (semibold) | 1.2 | Page hero headline (Phase 2), not used in Phase 1 components |

**Weights used:** 400 (regular) and 600 (semibold) only — exactly 2 weights. Load both via `next/font/google` weight array: `weight: ['400', '600']`.

**Minimum body font size: 16px on all viewports.** Never drop below 16px for readable content. 14px is permitted only for label-role text (nav links, button labels, captions).

**Accessibility:** Contrast ratios must meet WCAG AA minimum 4.5:1 for normal text and 3:1 for large text (18px+ or 14px bold).
- `#111827` on `#FFFFFF` = 16.1:1 — passes
- `#FFFFFF` on `#1B3A8F` = ~8.5:1 — passes (verify at project init with exact hex)
- `#FFFFFF` on `#00AEEF` = ~3.2:1 — passes for large/bold text only; do not use cyan as a background for body text

## Spacing Scale

All values are multiples of 4px (8-point grid base).

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gaps, inline badge padding |
| sm | 8px | Compact element gaps (nav link padding horizontal) |
| md | 16px | Default element padding, form field internal padding |
| lg | 24px | Section internal padding, card padding |
| xl | 32px | Layout column gaps, section vertical padding |
| 2xl | 48px | Major section vertical breaks (header height, footer padding) |
| 3xl | 64px | Page-level vertical rhythm (not used in Phase 1 shell) |

**Exceptions:**
- Minimum touch target: **44px height and width** for all interactive elements on mobile (LAYOUT-03). The Call Now button, hamburger icon, and all nav links must meet this threshold.
- Header height: **64px desktop / 56px mobile** — falls within the 2xl spacing band but declared explicitly to maintain predictable sticky positioning.
- Mobile drawer width: **280px** (fixed, not full-screen) — professional, not overwhelming on large phones.

## Component Contracts

### 1. Sticky Header

**Structure:** Three-zone flex row — `[Logo] [Nav] [CTA]`

**Desktop (≥768px):**
- Container: `max-w-7xl mx-auto px-6` — centered, 24px horizontal padding
- Height: 64px fixed
- Background: `--background` (#FFFFFF) with `border-bottom: 1px solid var(--border)`
- `position: sticky; top: 0; z-index: 50`
- Box shadow on scroll: `shadow-sm` (Tailwind) — appears after 1px scroll via scroll event listener or CSS `@supports (animation-timeline: scroll())`

**Logo zone (left):**
- `<img>` or `<Image>` from `next/image` pointing to `/public/logo.svg`
- Alt text: `"City Tech — Mobile Automotive Locksmith and Electronics Service"`
- Max height: 40px within the 64px header
- Links to `/` (homepage)

**Navigation zone (center):**
- Component: shadcn `NavigationMenu`
- Links: **Services** (with dropdown) | **Fleet** | **Request Service**
- Font: 14px, weight 400, `--foreground` color
- Active page indicator: bottom border `2px solid var(--primary)` on the active link
- Hover state: color transitions to `--primary` in 150ms

**Services Dropdown:**
- Triggered on hover (desktop) and click (keyboard / touch)
- Panel background: `--muted` (#F3F4F6)
- Border: `1px solid var(--border)`, `border-radius: var(--radius)`
- Two column groups: **Electronics** (left) and **Locksmith** (right)
- Group label: 14px, weight 400, uppercase, `letter-spacing: 0.08em`, `--muted-foreground` color
- Service items: 14px, weight 400, `--foreground` — on hover `--primary` with background `rgba(27, 58, 143, 0.06)`
- Each item links to `/services/[slug]`
- Populated dynamically from `/data/services.ts` — no hardcoded service names in this component

**CTA zone (right):**
- "Call Now" `Button` component, variant `default` (primary fill — `--primary` background, `--primary-foreground` text)
- Size: `sm` (shadcn size — produces ~36px height on desktop, meets 44px on mobile via explicit `min-h-[44px]`)
- Label: `Call Now` — on same line or stacked with phone number
- Phone number: displayed as `(555) 555-5555` placeholder — wrap in `<a href="tel:+15555555555">` for tap-to-call
- Phone number text: 14px, weight 600, `--primary` color, displayed adjacent to or below button label
- Combined element must be at minimum 44px tall on mobile

**Mobile header (< 768px):**
- Logo (left) — same as desktop, max-height 36px
- Phone number tap-to-call (center-right) — `<a href="tel:+15555555555">` styled as icon + number, 14px, weight 600
- Hamburger icon (far right) — Lucide `Menu` icon, 24px, min 44px touch target
- No navigation links visible in collapsed state
- Phone button stays visible alongside hamburger at all times (LAYOUT-01 requirement)

**Mobile Drawer (Sheet):**
- Component: shadcn `Sheet` with `side="left"` (slide in from left)
- Width: 280px
- Background: `--background`
- Header: City Tech logo + close button (`X` icon, Lucide `X`, 24px)
- Nav links stacked vertically: Services (expanded accordion, not dropdown), Fleet, Request Service
- Services section in drawer: shows both group labels (Electronics / Locksmith) with service links below each
- Each nav link: 16px, weight 400, `--foreground`, 44px min height, full-width, `border-bottom: 1px solid var(--border)`
- Active link: `--primary` color, `background: rgba(27, 58, 143, 0.06)`
- Drawer closes on: link click, outside tap, `Escape` key, close button click

### 2. Global Footer

**Structure:** Dark footer — `--muted` background, not primary blue (keeps it professional and accessible).

**Desktop (≥768px):**
- Container: `max-w-7xl mx-auto px-6`
- Padding: 48px top / 32px bottom for column area
- Three equal-width columns: Brand | Services | Contact

**Brand Column:**
- Logo (same SVG as header, max-height 40px)
- Tagline: `"Mobile Automotive Locksmith and Electronics Service"` — 14px, weight 400, `--muted-foreground`
- Service area: `"Serving DC, Maryland & Virginia"` — 14px, weight 400, `--foreground`
- Trust signal badges (stacked):
  - `"Est. 2016"` — 14px, weight 600, `--accent` color (#00AEEF)
  - `"NASTF Background-Checked Employees"` — 14px, weight 400, `--foreground`

**Services Column:**
- Column header: `"Our Services"` — 14px, weight 400, uppercase, `letter-spacing: 0.08em`, `--muted-foreground`
- All services from `/data/services.ts` listed as links
- Link style: 14px, weight 400, `--foreground`
- Hover: `--accent` underline (2px), color stays `--foreground`
- Links navigate to `/services/[slug]`
- Ordered: Electronics services first, then Locksmith services (matches nav dropdown order)

**Contact Column:**
- Column header: `"Contact"` — same style as Services header
- Phone: `(555) 555-5555` — 16px, weight 600, `--primary` color, `<a href="tel:+15555555555">` tap-to-call
- Availability: `"Available when you need us"` — 14px, weight 400, `--muted-foreground`
- Service area repeated: `"DC, Maryland & Virginia"` — 14px, weight 400, `--muted-foreground`

**Bottom Strip:**
- `border-top: 1px solid var(--border)`
- Padding: 16px vertical
- Left side: Social icon links — Facebook, Instagram, Linktree
  - Icons: Lucide `Facebook`, `Instagram` — for Linktree use a custom SVG or text fallback (`LT`)
  - Icon size: 20px, `--muted-foreground` color
  - Hover: `--primary` color, 150ms transition
  - `aria-label`: `"City Tech on Facebook"`, `"City Tech on Instagram"`, `"City Tech on Linktree"`
  - `href`: placeholder `#` until owner provides URLs (noted as deferred in CONTEXT.md)
- Right side: Copyright — `"© 2026 City Tech, LLC. All rights reserved."` — 14px, weight 400, `--muted-foreground`
- Bottom strip layout: `flex items-center justify-between`

**Mobile footer (< 768px):**
- Single column stack: Brand → Services → Contact → Social Strip
- Each section separated by `border-top: 1px solid var(--border)` with 24px padding
- Services list stays expanded (no accordion in footer on mobile)
- Social strip: centered on mobile, copyright below icons

### 3. Button Variants

| Variant | Background | Text | Border | Usage |
|---------|------------|------|--------|-------|
| `default` (primary) | `--primary` (#1B3A8F) | `--primary-foreground` (#FFFFFF) | none | Call Now, primary CTAs |
| `outline` | transparent | `--primary` | `1px solid --primary` | Secondary actions |
| `ghost` | transparent | `--foreground` | none | Nav items, icon buttons |
| `destructive` | `--destructive` | `--destructive-foreground` | none | Delete/destructive (not in Phase 1) |

**Sizes:**
- `sm`: height 36px, padding `8px 16px`, font 14px weight 400 — use for header CTA on desktop
- `default`: height 40px, padding `12px 20px`, font 14px weight 400 — standard usage
- `lg`: height 48px, padding `12px 24px`, font 16px weight 600 — hero CTAs (Phase 2)

**Mobile override:** All buttons must be `min-h-[44px]` on mobile regardless of size variant (LAYOUT-03).

## Interaction States

All transitions: `duration-150 ease-in-out` unless specified otherwise.

### Navigation Links (desktop)
| State | Visual |
|-------|--------|
| Default | `--foreground`, no decoration |
| Hover | `--primary` color, 150ms |
| Active (current page) | `--primary` color, `border-bottom: 2px solid var(--primary)` |
| Focus (keyboard) | `outline: 2px solid var(--ring)`, `outline-offset: 2px`, rounded |

### Call Now Button
| State | Visual |
|-------|--------|
| Default | `--primary` background, white text |
| Hover | Brightness +8% (Tailwind `hover:brightness-110`) or `#1E45A8` |
| Active (pressed) | Brightness -5% (`active:brightness-95`) |
| Focus | `outline: 2px solid var(--accent)`, `outline-offset: 2px` — cyan ring distinguishes from primary |
| Disabled | `opacity-50 cursor-not-allowed` |

### Hamburger Icon Button
| State | Visual |
|-------|--------|
| Default | `--foreground` |
| Hover | `--primary` color |
| Focus | `outline: 2px solid var(--ring)`, `outline-offset: 2px` |
| Open (drawer active) | Lucide `X` icon replaces `Menu` icon, same color rules |

### Footer Service Links
| State | Visual |
|-------|--------|
| Default | `--foreground`, no decoration |
| Hover | `text-decoration: underline`, underline color `--accent`, text color unchanged |
| Focus | `outline: 2px solid var(--ring)`, `outline-offset: 2px` |

### Footer Social Icons
| State | Visual |
|-------|--------|
| Default | `--muted-foreground` |
| Hover | `--primary`, 150ms |
| Focus | `outline: 2px solid var(--ring)`, `outline-offset: 2px`, rounded |

### Mobile Drawer Sheet
| State | Visual |
|-------|--------|
| Closed | Off-screen left |
| Opening | Slide in from left, 200ms ease-out, backdrop `rgba(0,0,0,0.4)` |
| Open | Full 280px width visible |
| Closing | Slide out left, 150ms ease-in |
| Backdrop | Click on backdrop closes drawer |

### Services Dropdown (desktop NavigationMenu)
| State | Visual |
|-------|--------|
| Trigger default | Same as nav link default |
| Trigger hover/open | `--primary` color, chevron rotates 180deg (150ms) |
| Panel enter | Fade in + translate Y -4px to Y 0, 150ms ease-out |
| Panel exit | Fade out, 100ms ease-in |
| Item hover | `background: rgba(27, 58, 143, 0.06)`, `--primary` color, 100ms |
| Item focus | `outline: 2px solid var(--ring)` inset |

## Accessibility Contract

These are non-negotiable requirements, not recommendations.

| Requirement | Implementation |
|-------------|---------------|
| Skip-to-content link | `<a href="#main-content">` as first focusable element in root layout, visible on focus |
| Landmark elements | `<header>`, `<nav>`, `<main id="main-content">`, `<footer>` — all present in root layout |
| Nav ARIA | `<nav aria-label="Main navigation">` on header nav, `<nav aria-label="Footer navigation">` on footer links |
| Drawer focus trap | When Sheet opens, focus trapped inside drawer, returns to hamburger button on close |
| Keyboard navigation | Tab order: Skip link → Logo → Nav links → Call Now button → main content |
| Touch targets | All interactive elements ≥ 44×44px on mobile |
| Color contrast | 4.5:1 minimum for all body/label text; 3:1 for large text ≥18px |
| `aria-expanded` | On hamburger button (reflects drawer state) and on Services nav trigger (reflects dropdown state) |
| `aria-current="page"` | Applied to active nav link matching current route |
