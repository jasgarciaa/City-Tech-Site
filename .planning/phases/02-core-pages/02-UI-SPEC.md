## Typography

Inherited from Phase 1 — no changes. New Phase 2 usages noted.

| Role | Size | Weight | Line Height | Phase 2 Usage |
|------|------|--------|-------------|---------------|
| Body | 16px | 400 (regular) | 1.6 | Service detail problem/solution/process copy, homepage section body text, quick form labels, trust signal descriptions |
| Label | 14px | 400 (regular) | 1.4 | Service card shortDescription, badge text (category label), carousel tile names, form field hints, section eyebrow labels |
| Heading | 20px | 600 (semibold) | 1.3 | Homepage section headings (Trust Signals, Fleet Teaser, Service Area, Quick Contact), service detail sub-headings (Problem, Solution, Process), fleet page section headings |
| Display | 28px | 600 (semibold) | 1.2 | Hero headline (homepage), service detail page H1, fleet page H1 |

**Additional display context:**
- Hero headline uses Display (28px/600) at mobile. At `md` breakpoint (≥768px) scale to **36px/600** using Tailwind responsive prefix: `text-3xl md:text-4xl`. This is the only responsive font-size exception — all other roles stay fixed.
- Section eyebrow labels (e.g., "Our Services", "Why Choose Us"): 14px, weight 400, uppercase, `letter-spacing: 0.08em`, `--muted-foreground` color — same pattern established in Phase 1 footer column headers.

**Weights used:** 400 (regular) and 600 (semibold) only — exactly 2 weights. This is a hard constraint.

## Color

All tokens confirmed live in `app/globals.css`. No new tokens are added in Phase 2.

| Role | Token | Hex | Usage |
|------|-------|-----|-------|
| Dominant (60%) | `--background` | `#FFFFFF` | Page background, service card surfaces, hero text container (transparent), quick form surface |
| Secondary (30%) | `--muted` | `#F3F4F6` | Alternating homepage section backgrounds (Trust Signals, Service Area, Footer CTA), service detail page sidebar/process steps background, fleet page alternating sections |
| Accent (10%) | `--accent` | `#00AEEF` | Accent reserved list below |
| Primary | `--primary` | `#1B3A8F` | Hero gradient, service card hover border, CTA buttons, section dividers |
| Destructive | `--destructive` | `#DC2626` | Form validation errors (inline, below field) only |

**Accent (`#00AEEF`) reserved exclusively for Phase 2:**
1. A single key phrase in the hero headline (e.g., "we come to you" or the service category phrase) — `text-accent` on that phrase only
2. Hero section key phrase only — CTAs in the hero use `--primary` (primary button) and `--primary` border/text (outline button); accent is NOT used on any hero CTA button
3. Category badge on service cards for **Locksmith** category only — Electronics cards use `--primary`, Locksmith cards use `--accent`
4. Step number callouts in the service detail page "Process" section (circular numbered badges)
5. Trust signal icon color (Lucide icons in the Trust Signals block)

**Accent is NOT used for:** body text, section backgrounds, form inputs, general paragraph text, headings (unless the single hero exception above).

**Hero gradient (D-19):** `background: linear-gradient(135deg, #1B3A8F 0%, #152E72 100%)` — full-width, dark blue. White headline, cyan accent on key phrase, no image dependency.

**Section alternation pattern for homepage:**
- White (`--background`): Hero, Services Grid+Accordion, Fleet Teaser, Logo Carousel, Quick Contact Form
- Muted (`--muted`): Trust Signals, Service Area statement, Footer CTA

This creates visual rhythm without adding color tokens.

### 2. Services Grid + Accordion (HOME-03 + HOME-04, unified per D-21)

One section, two visual layers sharing the same card set.

**Section heading:** `"Our Services"` — eyebrow label above, Heading size (20px/600) for the main heading.

**Grid:**
- Mobile: single column
- sm (≥640px): 2 columns
- lg (≥1024px): 3 columns
- Grid gap: 24px (`gap-6`)

**Service Card (shadcn `Card` component):**
- Background: `--card` (#FFFFFF)
- Border: `1px solid var(--border)` (#E5E7EB) default, `1px solid var(--primary)` on hover
- Border-radius: `var(--radius-lg)` (8px)
- Padding: 24px (`p-6`)
- Min-height: 200px
- Box shadow on hover: `shadow-md` transition 150ms
- Cursor: `pointer` (entire card is clickable — links to `/services/[slug]`)

**Card interior (top to bottom):**
1. Category badge: shadcn `Badge` component
   - Electronics: `bg-primary text-primary-foreground` (#1B3A8F / white)
   - Locksmith: `bg-accent text-accent-foreground` (#00AEEF / white)
   - Text: 14px, weight 400, uppercase, `letter-spacing: 0.06em`
2. Icon: Lucide icon, 24px, `--primary` for Electronics / `--accent` for Locksmith
   - Electronics icon: `Cpu` (default for all electronics) — executor may assign specific icons per service
   - Locksmith icon: `Key` (default for all locksmith)
3. Service name: `CardTitle` — 16px, weight 600, `--foreground`
4. Short description: `CardDescription` — 14px, weight 400, line-height 1.4, `--muted-foreground` — collapsed by default (first 2 lines visible, remainder shown on expand)
5. Accordion expand/collapse: "Show more" / "Show less" chevron link — 14px, `--primary` color, Lucide `ChevronDown` icon rotates 180deg when expanded

**Accordion behavior:**
- Component: shadcn `Accordion` with `type="single" collapsible`
- Each card is an accordion item. Expanding one does NOT collapse others (use `type="multiple"`)
- Height transition: CSS height animation from shadcn Accordion default — keep default, do not override
- Trigger: clicking anywhere on the card body toggles expand. Explicit "Show more" chevron provides affordance
- Expanded state: full `shortDescription` visible plus a "View Service Details →" link at bottom in `--primary` color

**"View Service Details →" link:**
- 14px, weight 600, `--primary` color
- Lucide `ArrowRight` icon inline, 14px
- Links to `/services/[slug]`
- Hover: underline decoration

### 5. Logo Carousel (HOME-05 + FLEET-04, reusable component)

**Component:** `LogoCarousel` — `"use client"` (requires JS for animation and hover-pause)

**Three clients (D-24):** Michael and Sons | Zipcar | Avis Budget Group

Real logo files are available at:
- `/public/logos/michael-and-son-logo@2x_b12650.webp`
- `/public/logos/zipcar-logo-png_seeklogo-333354.webp`
- `/public/logos/avis-budget-group-logo-png_seeklogo-317428.webp`

**Tile design:**
- Background: `--muted` (#F3F4F6)
- Border: `1px solid var(--border)`
- Border-radius: `var(--radius-md)` (6px)
- Min-width: 160px, height: 80px, padding: 12px
- Use `next/image` — `className="h-full w-auto object-contain"`
- Filter: `grayscale(100%)` default, `grayscale(0%)` on hover — CSS `filter` transition 200ms

**"And more" footer line:**
- Render below the carousel track (inside the `<section>`, after the track div)
- Copy: `"And more..."` — 14px, weight 400, `--muted-foreground`, `text-center`, `mt-4`

**Carousel behavior:**
- Infinite horizontal scroll via CSS `@keyframes` animation — no JavaScript animation library
- Tiles duplicated in DOM for seamless loop (two sets side by side, animation resets invisibly)
- Scroll speed: 30-second full loop (`animation-duration: 30s`)
- Pause on hover: `animation-play-state: paused` applied to the track on `mouseenter`, resumed on `mouseleave`
- No prev/next buttons — purely decorative motion

**Accessibility:**
- Wrap carousel in `<section aria-label="Fleet clients">` (or "Our clients" on homepage)
- Add `aria-hidden="true"` on the duplicated tile set
- `prefers-reduced-motion`: if `@media (prefers-reduced-motion: reduce)`, set `animation: none` and display tiles in a static flex row

## Accessibility Contract

Carried forward from Phase 1. Phase 2 additions:

| Requirement | Implementation |
|-------------|---------------|
| Heading hierarchy | Each page has exactly one H1. H2 for section headings. H3 for card titles within sections. No skipped levels. |
| Service cards | `<a>` wrapping the card for keyboard navigation. `aria-label` on card link: `"View [Service Name] service details"` |
| Accordion | Use shadcn Accordion which implements WAI-ARIA Accordion pattern. `aria-expanded` on triggers managed by Radix UI. |
| Logo carousel | `role="region"` + `aria-label="Fleet clients"`. Duplicate tile set: `aria-hidden="true"`. Reduced motion support required. |
| Breadcrumb | `<nav aria-label="Breadcrumb">` wrapping `<ol>` with `<li>` items. Current page: `aria-current="page"`. |
| Images (when real photos added) | `alt` text required. Hero background image: `alt=""` (decorative). Service images: descriptive alt. |
| Form labels | All form inputs have associated `<label>` via `htmlFor` / `id` pairing. No placeholder-only labels. |
| Form error messages | Error text associated to field via `aria-describedby`. Invalid state via `aria-invalid="true"` on the input. |
| Process step numbers | `aria-hidden="true"` on the visual numbered badge — step text is sufficient for screen readers |
| Related services row | `<ul>` list structure for the cross-links section |
| Touch targets | All interactive elements ≥ 44×44px on mobile (LAYOUT-03, carried forward) |
| Color contrast | All text passes WCAG AA. White on `--primary` (#1B3A8F): ~8.5:1. `--accent` (#00AEEF) on white: ~2.5:1 — accent MUST NOT be used as background for body text. |
