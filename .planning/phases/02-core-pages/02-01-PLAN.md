  <action>
Append the following CSS block to `app/globals.css` AFTER the existing `@theme inline { … }` block. Do not modify existing `:root` tokens or `@theme inline` contents — only add the new rules at the end of the file.

Exact CSS to append (copy verbatim, including comments):

```css
/* =========================================================================
   Logo Carousel (HOME-05, FLEET-04)
   - Infinite horizontal scroll via transform translateX(0) → -50%
   - Track contains two identical tile sets; -50% aligns set 2 start to viewport origin
   - Pause on hover via data-paused attribute on the track
   - Fallback: prefers-reduced-motion disables animation entirely
   ========================================================================= */
@keyframes carousel-scroll {
  from { transform: translateX(0); }
  to   { transform: translateX(-50%); }
}

.carousel-track {
  animation: carousel-scroll 30s linear infinite;
}

.carousel-track[data-paused="true"] {
  animation-play-state: paused;
}

@media (prefers-reduced-motion: reduce) {
  .carousel-track {
    animation: none;
  }
}
```

Why each rule matters:
- `@keyframes carousel-scroll` — drives the horizontal translation; -50% (not -100%) because the track contains 2 identical tile sets so -50% of track width equals one full set width (seamless loop).
- `.carousel-track` — the single class LogoCarousel.tsx will apply. Do NOT add hover/focus styling here — that belongs in the component JSX via data-attrs.
- `.carousel-track[data-paused="true"]` — matches the `data-paused="true"` attribute the component toggles on mouseenter/mouseleave.
- `prefers-reduced-motion` — WCAG 2.3.3 compliance; user-agent-level accessibility.

Do NOT add any `:hover` pseudo-class to the track — hover-pause is driven by the explicit `data-paused` attribute (keyboard users get the same behavior via focus-within, which JS toggles). Do NOT animate `margin-left` or `left` — `transform` is GPU-accelerated and the only acceptable property.

   - `{ name: 'AVIS' }`
5. Export a default function component `LogoCarousel({ ariaLabel = 'Our clients' }: LogoCarouselProps)`.
6. Inside the component:
   - Create `const trackRef = useRef<HTMLDivElement>(null)`
   - Define an inline tile renderer (either an inline sub-component in the same file called `CarouselTile` or a mapped inline JSX — inline component is clearer). A tile is a div with:
     - Tailwind classes: `flex min-w-[160px] h-20 items-center justify-center rounded-md border border-border bg-muted text-sm font-semibold text-muted-foreground grayscale hover:grayscale-0 transition-[filter] duration-200`
     - Children: the client name as plain text
7. Return JSX:
   ```tsx
   <section aria-label={ariaLabel} className="overflow-hidden bg-background py-10">
     <div
       ref={trackRef}
       className="carousel-track flex w-max items-center gap-6 px-6"
       onMouseEnter={() => trackRef.current?.setAttribute('data-paused', 'true')}
       onMouseLeave={() => trackRef.current?.removeAttribute('data-paused')}
       onFocus={() => trackRef.current?.setAttribute('data-paused', 'true')}
       onBlur={() => trackRef.current?.removeAttribute('data-paused')}
     >
       {/* First tile set — read by assistive tech */}
       {CLIENTS.map((c) => <CarouselTile key={c.name} name={c.name} />)}
       {/* Duplicate set — decorative, hidden from assistive tech */}
       <div aria-hidden="true" className="flex items-center gap-6">
         {CLIENTS.map((c) => <CarouselTile key={`dup-${c.name}`} name={c.name} />)}
       </div>
     </div>
   </section>
   ```

Critical implementation notes:
- The duplicate tile set MUST be wrapped in a `<div aria-hidden="true" className="flex items-center gap-6">` — NOT a fragment, NOT a span. The gap-6 on the wrapper preserves the same tile spacing across the seam. Research Pitfall 5 confirms tile duplication + -50% translation is the only approach that loops seamlessly.
- The `onFocus`/`onBlur` handlers are in addition to mouse handlers — keyboard users tabbing through the carousel pause it the same way. This matches WAI-ARIA guidance for scrolling content.
- Do NOT use `.contents` class for the duplicate wrapper — that collapses the flex gap and the seam becomes visible. Use a real flex container with matching gap.
- Do NOT introduce state (`useState`) — the animation is pure CSS, and data-attr toggle avoids a React re-render on every hover.
- Do NOT import anything from `@/data/services.ts` — clients are hardcoded per D-24.

Ensure `public/logos/.gitkeep` still exists (Phase 1 created it); do not remove it. If it is missing, create an empty file at `public/logos/.gitkeep` so the directory stays tracked.
